# ADR-0002: Raw function calling, not an agent framework

- Status: Superseded
- Date: 2026-10-05
- Related: Superseded by ADR-0007.
- Status detail: Superseded by ADR-0007

With one tool (`read_screen`) and a fixed two-step flow, a framework was judged unjustified ("why
two?"). The owner has since decided to use LangChain/LangGraph; ADR-0007 records the reasons and the
evidence, and is honest that with a single tool the framework's value is modest.
